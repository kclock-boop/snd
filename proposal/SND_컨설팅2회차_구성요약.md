# SND 컨설팅 2회차 구성 요약

## 목적

SND의 2회차 컨설팅은 1회차 수준진단을 반복 설명하는 회차가 아니라, 실제 PoC 범위와 운영 방식을 합의하는 회차로 설계했다.

## 핵심 메시지

1. 처음부터 전사 통합을 목표로 하기보다 `생산실적`, `공정 진행`, `품질/불량`의 세 축을 MVP로 확정하는 편이 빠르다.
2. 데이터는 복잡한 통합모델보다 `작업번호 중심 한 줄 이력` 구조로 시작하는 편이 실무 적용에 유리하다.
3. Dashboard는 같은 데이터를 보더라도 `경영자`, `관리팀`, `생산팀`, `품질팀`이 각각 다른 질문을 던질 수 있게 설계해야 한다.
4. PoC는 `데이터 정리 -> Dashboard MVP -> 보고 자동화 -> AI 보조기능`의 4단계로 나누는 편이 검증과 확장 판단에 유리하다.

## MVP 범위

### 생산실적 자동집계

- 일/주/월 실적 자동 집계
- 생산계획 대비 완료율 계산
- 보고서용 요약 테이블 자동생성

### 공정 진행 / 병목 모니터링

- MCT, Router 작업현황 집계
- 지연 작업과 설비 정지 이력 표시
- 계획 대비 실제 작업시간 비교

### 품질 / 불량 분석

- 불량유형 TOP 집계
- 재검 이력 연결
- 공정별 불량률 및 품질 문서 추적

## 권장 데이터 키

- 작업번호
- 품목번호
- 공정
- 설비
- 작업자
- 생산수량
- 검사결과
- 불량유형
- 등록일

## 역할별 Dashboard 관점

### 경영자

- 생산완료율
- 납기준수율
- 설비가동률
- 불량률
- 위험 알림

### 관리팀

- 계획 대비 실적
- 고객/품목별 납기위험
- 일/주간 실적 요약
- 보고서 초안 자동화

### 생산팀

- 작업현황
- 지연작업
- 병목공정
- 설비정지
- 계획 대비 실제 작업시간

### 품질팀

- 검사건수
- 불량유형 TOP
- 재검현황
- 공정별 불량률
- FAI 및 검사문서 이력

## 1. 회의 목적

- SND 현장업무 자동화 및 통합 Dashboard 구축 방향 공유
- 부서별 현행 이슈와 파일럿 PoC 범위 확인
- 우선 적용 공정 및 데이터 범위 협의
- 후속 실행 항목과 자료 준비 계획 정리

## 2. 발표/공유 내용 요약

### 2.1 추진 배경

- MES 이후 생산, 품질, 관리 데이터는 지속적으로 축적되고 있음
- 다만 실적 취합, KPI 보고, 공정 병목 확인, 품질 이력 분석은 여전히 수작업 비중이 높음
- 축적된 데이터를 현장개선과 의사결정에 바로 활용할 수 있도록 연결 구조가 필요함

### 2.2 제안 방향

- 작업번호 및 품목번호 기준으로 데이터를 연결
- 생산실적, 공정, 품질, 설비 이력을 통합 Dashboard로 시각화
- 생성형 AI를 활용해 병목, 불량, 납기위험, KPI 변동요인 분석 지원
- Data Room을 통해 도면, 검사성적서, FAI, 사진, 개선이력까지 함께 관리

### 2.3 초기 PoC 범위

- 생산실적 자동집계 및 KPI 자동화
- MCT·Router 공정관리 및 병목 분석
- 품질·불량·재검 분석
- 통합 Dashboard 시안 구성
- 작업번호 기반 Data Room 분류체계 초안 설계

## 3. 주요 논의 사항

### 3.1 부서별 현행 이슈

- 관리팀
  - 생산실적 및 KPI 취합에 수작업 비중이 높은지 여부 확인 필요
  - 일·주·월 보고 작성 방식 및 소요시간 확인 필요
  - 납기위험 사전 인지 방식 확인 필요

- 생산팀
  - MCT·Router 공정별 작업시간 및 지연 원인 데이터 확보 가능 여부 확인 필요
  - 설비이력 및 비가동 이력 관리 방식 확인 필요
  - 병목공정 판단 기준 확인 필요

- 품질팀
  - 검사결과, 불량유형, 재검 이력 데이터 구조 확인 필요
  - FAI 및 성적서 관리 방식 확인 필요
  - 반복불량 원인 추적 방식 확인 필요

### 3.2 파일럿 우선 대상 협의

- 파일럿 대상 품목/공정 후보
  - `MCT 또는 Router 중심 공정 1개`
  - `반복 생산되며 실적/품질 데이터 확보가 가능한 품목 1개`

- 우선 확인 KPI 후보
  - 생산실적
  - 납기준수
  - 공정별 작업시간
  - 설비 비가동/이상 이력
  - 불량건수 및 불량유형 TOP

- 우선 연계 데이터 후보
  - 작업지시
  - 생산실적
  - 공정별 작업시간
  - 검사결과
  - 불량/재검 이력
  - 도면 및 검사성적서

### 3.3 기대효과

- 생산실적 취합 및 보고시간 단축
- 공정 병목 조기 파악
- 품질 문제 대응속도 향상
- 부서 간 데이터 공유와 협업 속도 개선
- 향후 예방보전, 불량예측, 생산계획 최적화로 확장 기반 확보

## 4. 잠정 의사결정 정리

1. 이번 과제는 전사 대규모 구축보다 `파일럿 PoC 중심`으로 검토
2. 초기 범위는 `생산실적 + 공정관리 + 품질분석 + Dashboard` 중심으로 협의
3. 파일럿 대상은 `실적과 품질 데이터 확보가 가능한 공정/품목` 중에서 선정 필요
4. 내부 담당자는 관리, 생산, 품질 각 1명 이상 지정 필요
5. 다음 단계는 샘플 데이터 확보와 Dashboard 초안 검토로 진행
